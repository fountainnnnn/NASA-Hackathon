# NASA Space Apps 2026 project submission guide (local copy)

Source: https://www.spaceappschallenge.org/resources/project-submission-guide/ (fetched 2026-11-14)

## Deadlines
- **Opens:** Sat Nov 14, 9:00 a.m. (your Local Event's time zone)
- **Closes:** Sun Nov 15, 11:59 p.m. (Local Event time zone). Universal Event teams: Team Owner's local time.
- Anything saved/submitted after the deadline is not judged. Local judging times may differ; check with your Local Lead.

## Editing the project page
- Profile icon → **My Team** → **Project** tab → blue **Edit**.
- **Save Progress** often (visible only to the team until submitted).
- Toggle edit **Lock** ON while editing. Teammates can still break the lock and overwrite, so coordinate.
- Images: JPG/PNG/GIF up to 10 MB can be uploaded. **No video or document uploads**, so link those instead.

## Form fields
| Field | What it wants |
| --- | --- |
| Project Name | Name of the project |
| High-Level Project Summary | What you built, how it addresses the challenge, why it matters |
| Link to Project Demo | Public link to the demo. We submit a video of 30 s or less |
| Link to Final Project | Public link (site, repo, Drive, etc.), no login/permission/registration |
| Detailed Project Description | What it does, how it works, benefits, goals, tools/languages/hardware/software |
| Use of Super Intelligence (SI) | Whether and how AI tools were used (data collection only, judges don't see this answer) |
| NASA Data | Specific NASA data/resources used. **At least one is required for Global Awards** |
| Space Agency Partner Data and Other References | Every dataset, resource, tool, code, text and image used, open source included |

### SI (AI) rules
- Allowed as an accelerator, but **not** for coming up with the idea for solving the challenge.
- AI images/videos: **visible watermark**. Audio, code and data: acknowledge in descriptive text **and** metadata.
- Generated content must not use or modify NASA branding (logos, flags, mission identifiers).
- Judges see the watermarks/labels inside the project.

## Demo requirements
- **Video of 30 s or less** (our format). Over the limit means **not eligible for Global Judging**.
- Hosted externally, publicly accessible. English. A video may be spoken in another language with **English subtitles**.
- Judging criteria: **Impact, Creativity, Validity, Relevance, Presentation** (see the 2026 Judging and Awards Guide).

### 30-second video script
- 0:00 Your name and team name
- 0:02 The challenge and why you chose it
- 0:05 Project title and tagline
- 0:10 How it works: visuals/prototype, user experience, how NASA + partner data made it possible
- 0:20 to 0:30 The future: what it can do for people and the world


## Submitting
- All members confirmed at the **same Local Event**.
- All required fields completed, all in English.
- **No images, video, audio or likeness of anyone under 18.**
- Tick **Terms and Conditions** + **Confirm All Work is Original** → **Submit for Judging**. A banner confirms success.
- You can edit and resubmit until the deadline. The last saved submission is the one judged.

## Links & websites
- Public, no login. Test in a private window.
- New website? Optionally request a FortiGuard Web Filter Classification (Company Name: "N/A") so judges' networks don't block it.

## Certificate
After you submit, the certificate is at: Profile → Participant Information → "2026 NASA Space Apps Challenge" → **Download Participant Certificate** (PDF, Letter size, use desktop). The name comes from **Full Name** in your profile.
